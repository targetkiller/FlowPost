# Long Post

Long Post is a lightweight web tool for turning plain-text research notes, report summaries, and long-form analysis into mobile-friendly share images.

## Features

- Paste plain text and generate a clean long-form share card.
- Automatically uses the first paragraph as the article title when the title field is empty.
- Detects section headings such as `1/ 财报层面还是很强`.
- Editable subtitle, watermark, QR code link, footer title, and footer subtitle.
- Subtle tiled watermark across the generated image.
- Footer QR code for subscriptions, communities, or source links.
- One-click PNG export in the browser.
- Fixed blue visual style optimized for research-note share images.
- Research reports are rendered as a source card, conclusion card, numbered insight cards, and chart-evidence cards.
- Local chart assets can be loaded automatically and embedded as Base64 before export.

## 自动研报图表

FlowPost supports hidden Markdown directives generated by the report-summary workflow. Paste the generated summary directly; there is no need to upload screenshots in the browser.

```markdown
<!-- flowpost-source: Bank of America Global Research · 37页 · 2.0MB -->
<!-- flowpost-cover: /Users/tq/Documents/Financial Report/Summary/assets/report-slug/cover.jpg -->
<!-- flowpost-chart {"title":"NAND 现货急升","takeaway":"合同价能否跟上，决定景气是否真正上修。","image":"/Users/tq/Documents/Financial Report/Summary/assets/report-slug/chart-01.jpg"} -->
```

The directives are invisible in ordinary Markdown readers. In local development, FlowPost reads the selected image from `Summary/assets`, converts it to a Base64 data URL, and keeps it in the generated PNG. Keep this local asset workflow for report images; a static deployment cannot read paths from your Mac.

## Tech Stack

- Vite
- React
- TypeScript
- html-to-image
- qrcode.react
- lucide-react

## Local Development

Install dependencies:

```bash
yarn install
```

Start the development server:

```bash
yarn dev
```

Build for production:

```bash
yarn build
```

Preview the production build:

```bash
yarn preview
```

## Vercel Deployment

This project is a standard Vite static site and can be deployed directly to Vercel.

Recommended Vercel settings:

- Framework Preset: `Vite`
- Build Command: `yarn build`
- Output Directory: `dist`
- Install Command: `yarn install`

After connecting the GitHub repository to Vercel, every push to the production branch can trigger a fresh deployment.
