# Share Card Capture

Chrome extension that asks FlowPost to export its `article.share-card` element as a PNG, then downloads the returned image.

## Install

1. Open `chrome://extensions`.
2. Enable Developer mode.
3. Click Load unpacked.
4. Select this folder: `/Users/tq/Code/FlowPost/chrome-extension/share-card-capture`.

## Use

Open the FlowPost page, then click the extension icon. The PNG is generated by FlowPost's own export code and downloaded automatically.
